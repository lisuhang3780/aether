# 本地实拍图替换说明

把你的实拍图按下面的**文件名**放进 `assets/img/` 即可，**无需改任何代码**。
`index.html` 已配置：本地图不存在时自动回退到原 Unsplash 图（布局不会塌），图到位后刷新即生效。

|---|---|---|
| `hero-livingroom.jpg` | 首屏产品窗 | 极简客厅一隅 |
| `prod-watch.jpg` | 精选·极简腕表 | 配饰 |
| `prod-headphones.jpg` | 精选·声学耳机 | 数码 |
| `prod-chair.jpg` | 精选·休憩单椅 | 家居 |
| `prod-fragrance.jpg` | 精选·木质香氛 | 气味 |
| `story-studio.jpg` | 品牌故事·工作室 | 工作室 |
| `cat-home.jpg` | 分类·家居 | 器物与软装 |
| `cat-wear.jpg` | 分类·佩戴 | 配饰与眼镜 |
| `cat-bag.jpg` | 分类·携带 | 包袋与出行 |

## 提示
- 推荐尺寸：商品/分类 800–1200px 宽、4:5 或 1:1；首屏 1600px 宽 16:10；故事 1100px 宽 4:3.4；头像 200px 方形。
- 支持 `jpg` / `png` / `webp`，**文件名需与表格完全一致（含扩展名）**。
- 想换成别的文件名，直接改 `index.html` 里对应的 `src="assets/img/xxx.jpg"` 即可。
